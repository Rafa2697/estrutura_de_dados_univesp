# As visões das estruturas de dados

Nesta semana, vamos iniciar os estudos sobre as visões que podemos ter das Estruturas de Dados, posteriormente, o assunto será complementado em conteúdo da semana 3. Nesta disciplina, apresentaremos a organização dos dados de uma maneira conceitual, mas também estamos interessados na implementação dessas estruturas. Neste caso, você precisará entender que existem pelo menos três visões para cada uma das estruturas de dados, são elas: (i) visão da estrutura como um tipo abstrato de dados, a (ii) visão da aplicação dessa estrutura, e a (iii) visão da implementação. Nesta semana, vamos distinguir essas três visões.

Objetivos de aprendizagem

Ao final dessa semana, você deverá ser capaz de:

Compreender o significado de tipos abstratos de dados;
Distinguir entre as três visões de uma estrutura de dados;
Compreender as três visões através da implementação das estruturas de dados filas e pilhas como vetores.
